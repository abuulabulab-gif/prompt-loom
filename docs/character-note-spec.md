# LOOM キャラクターノート 設計仕様書

## 概要

現在の「メモ欄1つ」を、キャラクター創作者が使う**キャラクターノートシステム**に拡充する。
スプレッドシートで管理していた「設定の記録・プロンプトの保管・更新の追跡」をLOOM単体で完結させる。

### 設計方針
- キャラクターごとに独立した「ノート」を持つ
- メイン画面（ブロックエディタ）と**別タブ「📖 ノート」**として独立
- プロンプト表現と設定表現の橋渡しを明示的に管理
- 日付・タイトル・メモ付きのプロンプトログで変更履歴を追う

```
└──────────────────────────────────────┘
```

### データ構造

```javascript
promptLog: [
  {
    id:        string,
    ts:        number,     // Unix timestamp
    title:     string,     // "壁紙用・巫女衣装"
    tool:      string,     // "novelai" | "sd" | "mj" | etc.
    labels:    string[],   // ["壁紙", "完成度高"]
    posText:   string,     // Positiveプロンプト全文
    negText:   string,     // Negativeプロンプト全文
    memo:      string,     // 自由メモ
    blocks:    BlockSet,   // ブロック設定のスナップショット（復元用）
  }
]
```

### 機能仕様
- **手動記録**：「＋ 現在のプロンプトを記録」ボタンで任意に保存
- **自動記録**：COPYボタン押下時に自動保存（タイトルは空でも保存、後から編集可）
- **ブロック設定の復元**：ログからブロック設定を復元できる（今の履歴機能を強化）
- **フィルター**：ツール別・ラベル別で絞り込み
- **検索**：タイトル・メモのキーワード検索
- **件数制限なし**（今の履歴は20件上限。ログはIndexedDB容量まで保存）
- **エクスポート**：このキャラのログをCSV/JSONで書き出せる

## セクション3：タグ対応表（🔗）

### 目的
「設定上の表現（日本語）」と「プロンプト上の表現（英語タグ）」を対応づけて管理する。
スプレッドシートの「設定列」と「プロンプト列」に相当。

### UIレイアウト

```
┌─────────────────────────────────────────────────────┐
│ 🔗 タグ対応表                          [＋ 行を追加]  │
├──────────────────┬──────────────────────┬───────────┤
│ 設定（日本語）    │ プロンプト（英語）    │ 備考      │
├──────────────────┼──────────────────────┼───────────┤
│ 銀黒の長髪       │ silver hair,         │ 基本設定  │
│                  │ black hair,          │           │
│                  │ long hair            │           │
├──────────────────┼──────────────────────┼───────────┤
│ 深紅インナー     │ crimson inner hair   │ 特徴的    │
├──────────────────┼──────────────────────┼───────────┤
│ オッドアイ       │ heterochromia,       │           │
│ （右:赤/左:金）  │ red right eye,       │           │
│                  │ golden left eye      │           │
├──────────────────┼──────────────────────┼───────────┤
│ 巫女装束         │ shrine maiden,       │ デフォルト │
│                  │ miko dress,          │ 衣装      │
│                  │ detached sleeves     │           │
├──────────────────┼──────────────────────┼───────────┤
│ [新しい行...]    │ [タグを入力...]      │           │
└──────────────────┴──────────────────────┴───────────┘
                                                        
  💡 「プロンプトに追加」ボタンで対応するブロックに    
     タグを一括挿入できます                            
```

### データ構造

```javascript
tagMap: [
  {
    id:           string,
    label:        string,  // 設定上の名称（日本語）
    promptTags:   string,  // プロンプトのタグ（カンマ区切り）
    targetBlock:  string,  // どのブロックに追加するか（"face" | "outfit" etc.）
    notes:        string,  // 備考
    pinned:       boolean, // 上部固定
  }
]
```

### 機能仕様
- **「プロンプトに追加」**：行を選択して対象ブロックに一括追加
- **行の並び替え**：ドラッグ&ドロップ
- **「ブロックから取り込み」**：現在のブロック設定を自動でタグ対応表に展開するヘルパー
- **インポート/エクスポート**：CSV対応（スプレッドシートとの互換性）

## 実装メモ（Claude Code への指示用）

### ファイル分割案

```
src/
├── Loom.jsx              （タブ切替ロジックを追加）
├── CharacterNote/
│   ├── index.jsx         （タブコンテナ）
│   ├── ProfileSheet.jsx  （設定シート）
│   ├── PromptLog.jsx     （プロンプトログ）
│   ├── PromptLogEntry.jsx（1件分のカード）
│   ├── TagMap.jsx        （タグ対応表）
│   └── RecordModal.jsx   （記録モーダル）
```

### 既存機能との統合

- 現在の「プロンプト履歴（20件上限）」はPromptLogに統合・上限撤廃
- 既存のメモ欄（`character.memo`）は「背景・設定メモ」として移行
- COPYボタン押下時の自動スナップショットをPromptLogに保存するよう変更

### 段階的実装の順序

1. **タブ切替UI**（メイン画面に「📖 ノート」タブを追加）
2. **プロンプトログ**（既存の履歴機能を強化・移行するため先に作る）
3. **設定シート**（新規フィールドの追加）
4. **タグ対応表**（最も独立性が高いので最後）
5. **「プロンプトに追加」の連携**（ブロックエディタとの橋渡し）
