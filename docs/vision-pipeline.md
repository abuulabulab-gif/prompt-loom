# LOOM プロダクトビジョン：キャラクター制作パイプライン

※2026-07-15 `registry/projects.md` から移設（台帳の痩身）。ビジョンの正典はこのファイル。

## ビジョン（ABUU 2026-07-06明言）
「ゲームによくあるキャラクターメイクのプロンプト版」。
最終目標＝AIのすべてを駆使したキャラクター制作パイプライン。

## 工程順（依存関係で整理・凛が並べ直し2026-07-06、ABUU承認待ち）
```
①設定（名前・性格・ロア）        ← すべての工程の源泉
②プロンプト（ビジュアル正典化）   ← LOOMの担当。①を視覚言語に翻訳
③2Dモデル（立ち絵・三面図・表情差分）← ②の出力。以降の視覚工程の原型
④Live2Dモデル                    ← ③の立ち絵から直接作る（2D派生）
⑤3Dモデル                        ← ③の三面図から起こす
⑥声（ボイスモデル/TTS）           ← ①の性格に合わせて選定・学習
⑦セリフ（性格×声で話す）          ← ①×⑥。キャラが「生きて話す」最初の瞬間
⑧映像（モデル＋声＋セリフを動かす） ← ④/⑤×⑥×⑦の統合
⑨物語                            ← 全工程の到達点。①に還って設定を豊かにするループ
```
LOOMは①②を担う（キャラノート＝設定、ブロック/メーカー＝プロンプト）。
設計原則＝「基礎タグはブロック、制御はメーカー（こだわるならの設計）」。
ローカルAI制作ハブ構想（registry/projects.md 構想中枠）はこのパイプラインの器。
ドッグフーディング第1号＝朱羽凛（②まで完了・2026-07-06）。
