# AIイラスト向け プロンプト＆キャラクター管理アプリ 開発プロジェクト指示書
（Gemini作成 / 設計助言）

## 1. プロジェクトの目的
AIイラスト生成におけるプロンプトやキャラクター設定を、スプレッドシートの煩雑な管理から脱却し、
直感的かつモジュール化されたUIで効率的に管理・構築できるアプリケーションを開発する。
「スマホで暇なときにキャラ設定を組み合わせ、PCでガッツリ生成作業をする」というシームレスな体験を提供する。

## 2. ターゲットアーキテクチャと技術スタック
- 形式: Webアプリケーション ＋ PWA（プラットフォーム規約に縛られず、マルチデバイス対応）
- フロントエンド: React (Vite) または Next.js
- スタイリング: Tailwind CSS + shadcn/ui
- 状態管理・D&D: Zustand等、dnd kit

## 3. データ管理と保存のロードマップ
- フェーズ1（ローカル完結・完全無料）: IndexedDBで全データをブラウザ内保存。オフライン起動可。
- フェーズ2（クラウド同期）: Supabase導入。PC↔スマホ同期。将来の複数ユーザー基盤。

## 4. 将来的な拡張機能（クライアントサイド処理でサーバー代ゼロ）
- Image to Prompt: Transformers.js + WD14 Tagger をブラウザで動かし、画像からタグ抽出して振り分け。
- 3Dポーズからのプロンプト: React Three Fiber で簡易ボーンを操作、関節角度からタグを算出。

## 5. マネタイズ方針
- アフィリエイト: BTO PC（RTX搭載）、左手デバイス、ストレージ等のリンクを自然に配置。
- 投げ銭: Buy Me a Coffee / Ko-fi。

## 6. 追加実装アイデア
1. AIツール別の構文切り替え（SDの `()`、NovelAIの `{}` 等の強調記号をワンタッチ切替）
2. キャラ/プリセットのサムネイル登録（IndexedDBにBase64保存）
3. ショートカットキー対応（コピー・ブロック開閉等）

## 7. 当面のタスク
1. 作成済みJSXを App.jsx として完全動作する形に統合・補完。 → 本リポジトリの src/Loom.jsx で対応済み。
2. インラインスタイルを Tailwind CSS に置き換え、レスポンシブ対応。 → 段階Bの最優先TODO。

## Claude側の補足メモ（実装者向け）

- 構文切替について: 実態は「末尾suffix付与＋重み記号の変換」がほとんど。
  プロトタイプでは NovelAI/SD/MJ/Flux/DALL-E のsuffixと重み除去を実装済み。
  SDの `(tag:1.2)` ↔ NovelAIの `{tag}` 変換を足すならここを拡張。
- NSFW: 年齢確認ゲート＋デフォルト非表示トグルが定石。ホスティング(Vercel等)と決済の規約に注意。
- 複数キャラ: 「シーン合成」モードとして実装済み（人数宣言＋位置＋関係性＋BREAK区切り）。
