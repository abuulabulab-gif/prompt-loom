# LOOM v4 — フェーズ2 進捗報告書

## プロジェクト概要

**LOOM** は AIイラスト向けプロンプト＆キャラクター管理 Web アプリ。  
デプロイ先: `prompt-loom.com`  
スタック: Vite + React 18 + IndexedDB (Dexie) + PWA + Tailwind CSS

---

## フェーズ2 で実装した機能（全17件中12件完了）

フェーズ2 では「AIサイトの中で一番機能性・利便性が高いプロンプトサイト」を目指し、  
UIを過剰に複雑化せず、痒いところに手が届く機能を中心に実装した。

### ✅ 実装済み（12機能）

---

#### #1 ショートカットキー + 設定パネル
- `Ctrl+Enter` → プロンプトをコピー
- `?` → ショートカット一覧パネル（⚙️ボタン）を開く
- `[` `]` → 全ブロックを折りたたむ / 展開
- `P` / `N` → Positive / Negative タブ切替
- `1`〜`6` → AIツール切替（Midjourney, NovelAI, SD/Forge…）
- `Escape` → モーダルを閉じる
- `Ctrl+K` → コマンドパレットを開く
- ⚙️ボタンのショートカット一覧にはCtrl+Kも追記済み

---

#### #2 コマンドパレット（Ctrl+K）
- ヘッダーの `⌘K` ボタンまたは `Ctrl+K` で起動
- **fuzzy検索**でコマンドをインクリメンタル絞込
- ↑↓キーでナビ、Enter で実行、Esc で閉じる
- グループ別に整理：アクション / AIツール / パネル / アプリ設定 / キャラクター / ブロック
- 「ブロック」グループ: 選択するとそのブロックへスクロール＋展開
- 「キャラクター」グループ: 選択でアクティブキャラ切替
- シンプルモード切替・URL共有もパレットから操作可

---

#### #3 表情プリセット（顔ブロック専用）
- キャラ・顔ブロックの展開時、テキストエリア上部に表情バーを常時表示
- **14種類**: 😊微笑み / 😄大笑い / 😳照れ笑い / 😐真剣 / 😢悲しい / 😲驚き / 😠怒り / 😶無表情 / 😉ウインク / 😤むくれ / 😏ニヤリ / 😭号泣 / 😅汗顔 / 🤩興奮
- **トグル動作**: アクティブ中の表情をクリック → タグ削除（オフ）
- **クリーンスワップ**: 既存の表情タグを全削除してから新プリセットを適用（conflictなし）
- アクティブプリセットはブロックカラーでハイライト
- ✕クリア ボタンで表情タグのみ一括削除

---

#### #5 ネガティブ自動補完
- ネガティブブロック展開時、上部に「🚫 クイック追加」バーを表示
- 5プリセット: ⭐基本NG / 💫身体崩れ / ✨顔崩れ / 📘アニメ向け / 📷リアル向け
- クリックで既存テキストに **追記**（重複タグはスキップ）

---

#### #6 ランダムインスピレーション
- 各ブロックのstrength行に 🎲 ボタンを追加（ネガティブブロック除く）
- クリックで、そのブロックの**未使用タグ**からランダムに3つ追加
- 「何を足したらいいかわからない」ときのヒントとして機能

---

#### #7 サムネイル登録
- キャラクターパネル下部に画像アップロードエリアを追加
- アップした画像は **IndexedDB**（Dexieのthumbsテーブル）に保存
- 次回起動時もサムネイルを保持（メインの state row とは分離保存）
- ✕ボタンで削除

---

#### #8 LoRA管理フィールド
- キャラクターパネルに専用 LoRA セクションを追加
- 複数LoRAを「名前 + ウェイト」で構造化管理
- **SD / Forge** ツール選択時: `<lora:name:weight>` を出力に自動追加
- **NovelAI** ツール選択時: `{name:weight}` 形式で自動追加
- 他ツールでは出力に影響なし

---

#### #9 キャラバージョン管理
- キャラクターパネルに「🕐 バージョン管理」セクションを追加
- 名前を入力して現在のブロック状態を保存（最大10件）
- 「復元」で過去のブロック内容を上書き（確認ダイアログ付き）
- 個別削除も可能

---

#### #10 ブロック転送（他キャラへコピー）
- 各ブロックヘッダーに `→` ボタンを追加（キャラが2人以上のとき表示）
- クリックで他のキャラ一覧がドロップダウン表示
- 選択すると **そのブロックのテキスト**を対象キャラの同じブロックにコピー
- 衣装・構図などを複数キャラで使い回すときに便利

---

#### #11 プロンプトバランスメーター
- 出力バーの Positive タブに薄い色帯を表示
- 各ブロックのタグ数を**比率で可視化**（ブロックカラーのセグメント）
- ブロックアイコン＋タグ数の内訳も小さく表示
- タグが偏りすぎていないか一目でわかる

---

#### #13 バリエーション展開
- 出力バーに「🎲 バリエ」ボタンを追加
- クリックで **4種類のバリエーション**を生成してパネル内に一覧表示
- 各バリエーションに個別 📋 コピーボタン
- **生成ロジック**:
  - `quality` / `face` / `attribute` / `body` → **固定**（キャラの外見は変えない）
  - `artstyle` / `composition` / `effect` / `background` / `lighting` → タグを55〜90%ランダム保持 + 未使用タグを0〜2個ランダム追加
- 「↻ 再生成」で別セットを生成
- ✕で閉じる

---

#### #14 差分プレビュー（ComparePanel全面強化）
- キャラ比較パネルを**タグ単位のdiff表示**に全面リニューアル
- 変更されたブロックを展開して、タグを1つずつチップとして表示
  - **Aのカラー** でハイライト: キャラAのみのタグ（追加）
  - **Bのカラー** でハイライト: キャラBのみのタグ（削除）
  - グレー: 両方に共通するタグ
- ブロック名・アイコンを各行に表示
- 相違ブロック数バッジ、凡例付き
- 同一ブロックは「（同一）」と省略してノイズを減らす

---

#### #15 プリセット共有URL
- キャラクターパネルの「🔗 URLで共有」ボタンで現在のキャラをURLエンコード
- コマンドパレットからも操作可能
- URLを開いた人のアプリに**キャラが自動インポート**（URLパラメータ `?share=` を検出）
- エンコード内容: キャラ名・絵文字・カラー・全ブロックのテキストと有効/無効状態

---

#### #17 シンプル/詳細モード
- ヘッダーに「📋 Simple / 🗂 Advanced」トグルを追加
- **シンプルモード**: quality・artstyle・face・outfit・composition・negative の6ブロックのみ表示
- **詳細モード**: 全12ブロックを表示（デフォルト）
- 初心者やサクっと使いたいときに便利

## インフラ / 技術的改善

### Tailwind CSS移行
- インラインスタイルを 111箇所 → 55箇所 に削減
- 残り55箇所は全てキャラカラー等の**動的値**（`block.color`, `c.color` 等）で、  
  ビルド時に静的クラスを生成できないため意図的にインラインで保持

### CSS変数 `--prompt-text` の追加
- ダーク: `#7fa8ff`（青系）/ ライト: `#2563eb`（青系）
- テーマ対応のプロンプトテキスト色として Tailwind クラス `text-prompt` で参照可能

### BlockCard の `v` 変数バグ修正
- Tailwind移行時に `v.dim` / `v.muted` が未定義のまま残っていた参照を全修正
